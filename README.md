# DevFund

> A developer-focused support platform — back shipped software, not just creators.

DevFund is a standalone product that lets developers earn support for the tools and projects they actually ship. Unlike GitHub Sponsors (buried, person-focused) or Buy Me a Coffee (too generic), DevFund is built around the product: discovery by tech stack, tiers tied to real software access, and GitHub-native integration.

## What it is

- **Project pages** — repo link, live demo, tech stack tags, support tiers
- **Dev profiles** — all your projects in one place
- **Discovery feed** — find new tools by category, stack, or trending
- **Supporter dashboard** — track what you back, get changelog updates
